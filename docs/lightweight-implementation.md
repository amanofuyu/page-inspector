# 只读查看器轻量化实现

本次将扩展收敛为数据、SEO、网络三个查看入口。侧边栏提供数据和 SEO，网络仅在 DevTools 可用。

本文件记录首次轻量化改动与当时验证结果。2026-10-10 后续补齐的 SEO 查看分类、手动响应头与 hreflang 请求，以及最新产物与验证结果见 [SEO 查看功能实现](seo-viewer-implementation.md)。

## 数据链路

删除分析排名、高级查询、保存查询、字段关注及快照比较。删除工作区索引、payload Worker、关注存储和相关后台消息。路径类型、数组空洞标记和路径格式迁入 `features/nuxt/path.ts`。

字段详情在 `features/nuxt/detail.ts` 中直接访问已解析数据，仅为当前选中字段生成有界局部树。保留 Map 键值、Set、二进制按字节显示、Nuxt 包装、数组空洞、共享引用和循环引用。元信息聚合根继续使用其展示树。

非数据页暂停 Nuxt 采集，切回后重读。查看独立网络响应时不触发页面 payload 采集，避免覆盖用户选中的响应。页面身份、采集取消、体积上限和迟到结果拦截继续使用。

## SEO 与网络

DOM 和 HTML 直接显示各自字段，不构造缺失项，不执行差异或问题规则。保留 JSON-LD 原文、格式化预览和语法错误。移除结构比较时的 JSON 排序，保留原字段顺序与数字文本。

DOM 在打开 SEO 或页面更新后采样；HTML 仅在 DevTools 用户点击时读取。HTML 继续验证当前文档、URL、导航时间及响应预算，并通过独立 Worker 解析。移除参考 HTML 请求、刷新捕获状态机和跨面板基线缓存。

网络会话在 DevTools 面板打开期间监听元信息，正文按需读取。移除业务候选、来源关联和跨导航保留。保留记录、文本缓存、超时和生命周期预算。现有响应头只供 SEO 读取 `content-type`、`link` 和 `x-robots-tag`，没有新增完整响应头查看能力。

## 界面与依赖

静态 CSS 背景替代 WebGL，简单透明度过渡替代 Motion；保留减少动态效果偏好及原生模态框焦点行为。移除 `motion-v`、Pinia、Unhead 和未使用的类名工具依赖。保留 Vue、WXT、Ark UI、devalue、parse5、消息库及按需 JSON 高亮。

## 自查与验证

新增局部字段详情回归，更新 SEO、网络及组件测试。删除已移除功能专用测试，保留采集、外部读取、特殊类型、复制、预算和请求失效测试。浏览器验收脚本同步更新，但运行前需用户确认。

最终验证通过 126 项单元测试、三个应用类型检查、全仓 lint 和扩展生产构建。e2e 脚本已更新，但尚未运行，等待用户确认。

| 产物      | 改动前     | 改动后    |
| --------- | ---------- | --------- |
| 主界面 JS | 724.30 kB  | 433.94 kB |
| 总产物    | 约 1.30 MB | 966.70 kB |

主界面 JS 减少约 40%，生产构建已无 500 kB 分块警告。产物体积不等同于运行时内存或加载时间。

审查修复包括：网络修订后重新派生列表、旧行关闭事件不影响新详情、手动刷新保留搜索条件、独立响应查看不触发页面采集，以及清空记录时取消正文并拦截迟到 HAR 回填。数组空洞回归样例通过逐项赋值构造，避免格式工具将稀疏数组转换成含 undefined 的密集数组。
