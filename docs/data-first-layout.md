# 数据优先布局

本次采用「专注画布」的精简页头和底部工作区导航，结合「数据树与详情分栏」展示内容。

- 页头保留名称、当前地址、页面与来源信息入口、重新读取和主题切换。
- 页面标题、完整地址、采集时间、来源与范围说明收进统一的「页面与数据来源」弹窗，页头信息按钮和底部来源按钮打开同一个弹窗。读取失败和快照警告仍直接展示。
- 数据分类和搜索紧接页头，展示上限提示随数据树内部滚动，去掉大面积页面卡片、体积指标和数据区重复边框。
- 左侧点击字段查看详情，独立箭头控制展开；复制当前值、当前属性名、带类型数据、路径和关注操作集中在详情区。
- 详情沿用现有 Worker 的字段读取、来源追溯和 10,000 节点／60 层预算。“带类型数据”继续保留类型与引用；“复制当前值”去掉查看器元数据，字符串为原文本，普通对象和数组为 JSON，特殊类型与引用为 JavaScript 表达式。已截断的值不冒充完整数据复制，属性名仍可直接复制。
- 元信息聚合根和 Map 条目等非独立字段展示当前视图数据，不向 Worker 发出无效路径查询，也不开放无效的关注操作。
- 数据树和字段详情始终在各自面板内滚动，分类、搜索和底部导航保持原位，滚动到底部也不带动外层。
- 宽度不足 600px 时，树和详情上下均分剩余高度；收起详情后数据树占满剩余空间。来源弹窗的标题与底部操作固定，正文在限定高度内独立滚动，不挤占数据区域；支持关闭按钮、Esc 和点击遮罩关闭，关闭后恢复入口焦点。
- 底部保留采集状态、时间、来源体积，以及数据、分析、检索、关注和 SEO 入口；DevTools 继续提供网络入口。

同一文档刷新会保留仍存在的选择路径，并将详情更新为新快照中的值。页面、应用、分类切换或所选字段消失后回到当前分类根节点。收起详情后重新点击字段会打开详情区。

分析和查询结果原有的就地详情、关注规则及网络响应查看保持独立；不额外发起网络采集。

验证记录：

- ESLint、扩展类型检查、生产构建通过。
- 119 项单元测试通过，其中 5 项覆盖选择随刷新、分类切换、字段删除和特殊类型更新。
- 用户确认后执行浏览器 E2E：19 项侧栏用例通过，覆盖宽窄布局、字段详情、键盘操作、复制导出、主题、关注、工作区切换、SEO、动效和提示浮层。
- 真实 Nuxt 3 SSR、Nuxt 4 静态外部 payload 两组配置共 10 项用例通过，覆盖特殊类型、原文导出、导航、分析、关注和 SEO。
- 2 项真实 DevTools 用例通过，覆盖网络响应查看、固定标签页与 SEO 来源对照。

本次内部滚动修正通过 15 项相关 E2E 场景。新增 900×780、560×780、320×480 三种尺寸的真实滚轮测试，验证两块面板互不带动、滚动到底部不传递给外层，以及搜索、详情开关和来源信息展开后的高度约束；Lint、类型检查和生产构建通过。

当前值与属性名复制新增 11 项单元测试，单元测试共 130 项通过；17 项相关 E2E 通过，包含真实剪贴板读取、纯文本／JSON／BigInt 复制、检索详情入口、截断值不覆盖剪贴板，以及原有复制与关注操作。Lint、类型检查和生产构建通过。

页面来源信息改为原生模态弹窗后，15 项相关 E2E 通过，覆盖两个入口、关闭按钮／Esc／遮罩关闭、入口焦点恢复、背景不可交互、长地址换行、明暗主题、内部滚动与来源折叠动效。320×480 窄视口保留边缘留白，打开弹窗前后数据区的尺寸和滚动位置保持一致。Lint、类型检查和生产构建通过。
