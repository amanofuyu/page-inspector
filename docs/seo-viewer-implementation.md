# SEO 查看功能实现

日期：2026-10-10。参考本机安装的 Detailed SEO Extension 2.2.7，复刻其页面 SEO 数据查看能力，沿用本项目界面，不对齐原插件的视觉和交互状态。

## 功能范围

| 分类       | 实现内容                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 概览       | 页面地址、标题、描述、canonical、Robots、X-Robots-Tag、关键词、发布者、语言；H1–H6、图片、链接与字数；robots.txt 和 sitemap.xml 入口 |
| 标题       | 按文档顺序查看 H1–H6，用缩进表示级别；复制全部标题、下载 TXT                                                                         |
| 链接       | 总量、去重、内外链与其他协议统计；类型与关键词筛选、去重、地址复制、地址 TXT 和明细 CSV                                              |
| 图片       | 缩略图、原始及实际地址、alt、title、尺寸；区分空 alt、缺少 alt 和有 alt 文本；筛选、复制及 TXT／CSV 下载                             |
| 结构化数据 | JSON-LD 原文和错误、Microdata 嵌套属性及 itemref、hreflang 标签；按类型筛选和 JSON 下载；手动检查目标 HTTP 状态及回链                |
| 社交分享   | Open Graph、X／Twitter 原始标签和图片、标题、描述预览；Twitter 缺少字段时使用 Open Graph 回退                                        |
| 工具       | 外部 SEO 服务、站内搜索、非 HTTPS 收录地址搜索和重复文本查找；均由用户点击在新标签页打开                                             |

按先前的轻量只读要求，不纳入 User-Agent 修改、页面 nofollow 高亮、右键菜单注入和搜索结果页的自动增强功能。没有增加评分、问题规则、跨来源比较或持续分析任务。

## 采样与请求

DOM 和文档响应 HTML 使用相同字段、资源和 Microdata 模型。JSON-LD 保留数字文本、重复键与原顺序；Microdata 按 itemscope 边界组织属性，处理重复属性、多个属性名、URL 值、时间值与 itemref，限制循环、深度、访问次数和展开体积。

链接以内外链主机名分类；相对地址以第一条 base href 解析，原始属性独立保留。DOM 图片优先显示浏览器选用的 currentSrc，尺寸优先采用声明值、其次自然尺寸；HTML 仅提供静态声明信息。字数按块边界与空白分隔计数，不代表中文字数，也不执行计算样式或强制布局。

DevTools DOM 采样可以使用唯一关联的已观察 SEO 响应头，不因此读取正文。缺少可关联记录时保留「未读取响应头」，可由用户点击执行 HEAD。HEAD 样本单独保存，显示最终地址、状态和采样时间，不将重新请求的结果写成原文档响应。

hreflang 按单条用户操作请求，匹配完整解析后的 alternate hreflang 地址来判定回链。响应非 HTML、非成功状态或解析不完整时明确区分失败、无回链与无法确认。响应逐块检查实际字节数，上限 5 MiB；HTML 解析使用已有独立 Worker。额外请求不携带凭据，最多并发三条，15 秒超时；换页、来源切换、重采样、离开工作区、取消和卸载后拒绝迟到结果并释放计时器。

## 轻量与安全展示

沿用现有 Vue、Ark UI、parse5，不安装新依赖，不添加后台消息或扩大权限。资源列表首屏 50 项，按需追加；导出覆盖全部已采集匹配项。HTTP(S) 地址才可打开或预览；图片按需、懒加载且不发送来源地址。CSV 正确处理引号和换行，并阻止字段被电子表格解释为公式。

DOM 保留 250 毫秒扫描预算、100,000 节点预算、12,000 条标签预算、2 MiB 标签消息预算和单项长度上限。正文计数限制 1 MiB 文本；Microdata 最多 2,000 节点、30 层和 12,000 次访问。达到预算时展示部分采集状态，不将「未采集到」宣称为缺失。

## 页面排版

工作区按「来源与读取操作 → 分类导航 → 分类内容 → 采样详情」组织。DOM／HTML 来源选择收进页头下拉框，只保留一层内容分类页签。分类使用单行下划线导航，窄侧栏横向滚动，选中项在切换或重建后保持可见，不带动工作区纵向滚动。

概览将链接、图片和正文词数集中展示，页面信息与索引设置分别使用标签／值列表，标题分布单独展示。宽面板中页面信息与索引设置并列，窄侧栏中纵向排列。正文计数标为「正文词数」，与按空白分隔的实际统计口径一致。

链接、图片采用「统计 → 筛选与导出 → 明细」结构。链接条目按名称、完整目标地址、rel／title／原始地址排列，内外链用不同颜色的标签区分，复制入口固定在条目右上角。图片卡片展示文件名、alt 状态、完整预览、尺寸和 alt／title；完整图片地址与原始地址占用卡片全宽，避免挤压属性内容。宽面板采用双列图库，窄侧栏单列；预览与属性根据卡片自身宽度分栏。透明图片使用棋盘底，预览不裁切原图；加载失败或不支持的地址显示占位，地址更新后恢复预览，无地址时禁用复制。筛选、去重、50 条分页和全部匹配项导出继续保留。

标题保留文档顺序和级别缩进；JSON-LD、Microdata、hreflang，以及 Open Graph、X／Twitter 标签分别分组。分组仅调整展示，保留字段筛选、完整复制和原有分页预算。

JSON-LD 折叠时仅显示名称、类型和字符数，不展示外层部分预览；展开后显示带行号的格式化代码，并支持键盘聚焦、横向与纵向滚动。高亮复用按需加载的 Shiki 和明暗主题；加载期间或失败时保留纯文本。格式化仅调整标记之间的空白，保留大整数、重复键、原顺序与字符串转义；「复制 JSON」和「复制标签」始终使用完整已采集原文，展开内容继续遵守 16,000 字符预算并显示截断提示。

SEO 分类内容使用独立底色和边框，工作区、分类、分组与字段标题分别采用 22、20、18、16px 字号。分组标题使用灰底和左侧强调线，字段正文使用内容底色，展开内容使用次一级灰底；来源、位置和字符数使用辅助文字样式。概览、资源、社交预览与工具分组沿用相同层级，明暗主题及窄侧栏均通过共用表面变量适配。

分享预览与原始标签分区；外部工具按页面验证、链接与流量、搜索收录和站点资料分组。响应头读取留在索引设置中，采样详情移到页尾，顶部仍显示当前采样时间。本次排版没有新增依赖。

全项目界面字号由共用变量统一上调 2px：辅助信息为 14px、正文为 16px，其余层级为 18、20、22、26px。数据、SEO、网络、弹窗、代码和传送到页面根节点的菜单均使用同一组变量。紧凑文字按钮的最小高度调整为 32px，选择器允许随内容增高；窄侧栏通过换行和滚动适配。
