# non.fan 配色参考与界面风格记录

当前界面按用户后续要求采用磨砂玻璃卡片、弥散渐变、背景模糊和微噪点；non.fan 仅作为配色来源。以下网站研究和首版方案保留为历史记录。

## 研究范围

研究日期：2026-09-28。参考仓库为 [2nonnon/non.fan](https://github.com/2nonnon/non.fan)，源码固定到提交 `42108202f82e52045631f0ee51f8fd6c29c42421`。

实际访问了 [首页](https://www.non.fan/)、[音乐页](https://www.non.fan/music)、[文章归档页](https://www.non.fan/renarrate)，查看了 1440 × 1000 桌面视口和 390 × 844 首页窄屏视口。导航过渡、专辑弹窗和歌词背景的实现通过源码核对，未逐一做交互验收。线上部署是否对应上述提交尚未核实。

仓库登记的 `2nonnon.vercel.app` 地址在研究时返回部署不存在，正式域名可以访问。

## 整体判断

这是围绕のん（能年玲奈）展开的艺术家粉丝网站，包含人物展示、音乐和文章归档。视觉基调是深色、克制的界面框架，配合鲜明的内容构图。

- 首页：大片深色留白、柔软饱满的白色标识与人物叠加，形成海报感。
- 音乐页：醒目的红色大标题、斜向排列的立体唱片封面、细条形位置指示器。
- 文章页：收窄正文宽度，直接排列标题、时间和摘要，以细红色竖线和间距分组。
- 不同内容采用不同布局，统一感主要来自背景、字体、强调色和精简的导航。

这套风格的重点是内容主次清楚、界面装饰克制，表达性集中在核心视觉上。

## 配色与主题

## 字体、布局与组件

字体组合为 Inter、Kosugi Maru 和系统无衬线字体，基准字号 16px。西文干净，日文带有圆润感；中文翻译另有使用系统字体的工具类。字体加载配置见 [Nuxt 配置](https://github.com/2nonnon/non.fan/blob/42108202f82e52045631f0ee51f8fd6c29c42421/nuxt.config.ts)。

布局主要采用 1280px 最大内容宽度、两侧 24px 内边距和 768px 桌面断点。文章另行限制正文宽度。页头仅保留小标识与菜单入口，视觉重量较低。

- 标题、正文、时间与摘要通过字号、字重、透明度和间距区分。
- 文章列表很少依赖卡片底色、描边和阴影，层级较平。
- 圆角按内容使用：唱片封面接近直角，专辑弹窗有明显圆角。
- 弹窗采用浅底深字，形成与深色页面的反差；移动端呈底部面板，桌面端居中。
- 窄屏首页重新编排人物与标识的位置，包含镜像构图，不是简单缩小桌面版。

参考：[首页](https://github.com/2nonnon/non.fan/blob/42108202f82e52045631f0ee51f8fd6c29c42421/app/pages/index.vue)、[文章归档](https://github.com/2nonnon/non.fan/blob/42108202f82e52045631f0ee51f8fd6c29c42421/app/pages/renarrate/index.vue)、[专辑弹窗](https://github.com/2nonnon/non.fan/blob/42108202f82e52045631f0ee51f8fd6c29c42421/app/features/song/album-dialog.vue)。

## 动效语言

根据源码，动效与内容形式关联较强：

- 导航：汉堡按钮转为关闭图标，浅色全屏菜单通过圆形裁切展开，链接悬停出现红色下划线。
- 唱片：透视堆叠、滚动切换和悬停位移，用空间关系表达音乐作品集合。
- 歌词：从封面提取颜色，生成缓慢变化的模糊渐变背景。
- 签名：逐段绘制 SVG 笔画。

因此，渐变和立体效果属于音乐等内容场景的表达，不宜推导为所有页面都要铺设动态背景。

参考：[导航](https://github.com/2nonnon/non.fan/blob/42108202f82e52045631f0ee51f8fd6c29c42421/app/components/nav.vue)、[音乐页](https://github.com/2nonnon/non.fan/blob/42108202f82e52045631f0ee51f8fd6c29c42421/app/pages/music/index.vue)、[歌词视图](https://github.com/2nonnon/non.fan/blob/42108202f82e52045631f0ee51f8fd6c29c42421/app/features/song/lyric-base.vue)。

## 对 Page Inspector 的首版建议（历史）

以下为最初针对本项目提出的设计判断；当前视觉方向已调整为文末的磨砂卡片方案。

建议提炼深色中性背景、近白文字、少量强调色、扁平列表和清晰文字层级。数据面板更适合借鉴文章页的组织方式；首页的海报构图与音乐页的立体唱片可保留为风格理解，不直接套入日常数据操作。

| 当前或规划区域         | 可借鉴的表达                                                     |
| ---------------------- | ---------------------------------------------------------------- |
| 侧边栏与 DevTools 框架 | 降低页头重量，减少重复卡片包裹，通过分隔线、留白和选中态组织区域 |
| Payload 体积分析       | 让总量和主要指标突出，用克制的横条及排序列表展示占比             |
| 高级检索               | 紧凑工具栏、清晰条件标签、统一结果行，保证键盘焦点可见           |
| 字段关注               | 用细强调线或小标记提示关注状态，保持路径和值易于扫描             |
| 请求关联               | 用对齐的列、时间与状态层级表达对应关系，强调色只突出关键关联     |

实施时需要另行确定的边界：

- 保留当前浅色、深色和跟随系统的主题能力；浅色配色需要独立设计。
- 当前使用 DaisyUI 主题变量，可以先映射语义变量并调整布局，不必为了参考风格更换组件技术栈。
- 中文界面优先使用适合中文的字体回退；字段路径、代码和数值使用等宽字体。扩展默认不依赖外部字体网络请求。
- 主色与错误状态需要明确区分，并验证实际文字及控件的对比度。
- 保留文本选择、复制、可发现的滚动区域和焦点提示。参考站全局禁止选择文字并隐藏滚动条的做法不适合直接迁入数据工具。
- 交互反馈可以更短、更轻；装饰性动画不能影响搜索、展开和滚动，并应尊重减少动态效果的偏好。

## 首版界面落地

2026-09-28，按上述参考完成现有侧边栏的首版视觉调整：

- 深色采用 `#121212` 主背景、近白正文和局部红色强调；浅色采用暖白背景，并保留浅色／深色／跟随系统的存储设置。
- 页面信息与数据区域改为连续布局，以细线、间距和字重组织层级，移除原有外层圆角卡片。
- 突出当前已采集原文的总量，并显示来源数量。此数字继续沿用已有来源文本字节数求和，不代表网络传输体积，也不是尚未实现的字段体积分析。
- 数据树用图标提供路径与值复制，保留操作提示与可访问名称；键、类型和值可换行，复制按钮保留独立空间。
- 搜索结果以细红线标记路径；原文高亮背景、来源详情及空／错误／加载状态使用同一套语义配色。
- 保留文本选择、可见滚动条、键盘焦点提示和减少动态效果的支持；不引入外部字体或新增依赖。

本轮针对现有界面，体积分析、高级检索／字段关注和 DevTools 请求关联仍按独立功能方案推进。验证结果见 [实现验证记录](validation.md)。

## 当前界面：磨砂玻璃卡片

后续用户明确要求：稍微提高文字对比度，整体采用磨砂玻璃、卡片、弥散渐变、高斯模糊和微噪点，先前参考仅保留配色。

- 配色：继续使用深灰、红色主强调，以及黄色和绿色辅助光晕；浅色使用暖白底。
- 卡片：页面信息、Payload 数据、来源详情以及空／加载／错误状态采用半透明表面、细高光边缘和柔和阴影，背景模糊为 `24px`；卡片圆角统一为 `12px`，内部表面与控件主要使用 `6–8px` 圆角。
- 背景：使用三组静态径向渐变和 `42px` 高斯模糊；本地 SVG 噪点纹理叠加在背景层，不依赖远程图片或字体。
- 阅读：浅色主要文字为 `#1C1A18`、辅助文字为 `#59534E`；深色主要文字为 `#FFFFFF`、辅助文字为 `#CBC5C0`。路径、时间、类型标签等小字适度增大。
- 数据区：使用更高不透明度的内层表面，让背景效果与树形数据、原文和搜索结果之间保持清晰层次。
- 排版：卡片间距和常规内侧对齐基线统一为 `12px`，窄屏仅收紧页面外侧边距；标题、状态、采集时间、操作按钮与 Payload 指标分别横向对齐。
- 控件：分类切换采用等宽分段按钮，主题选择器、搜索框和操作按钮与卡片表面统一。
- 展开热区：有子节点时，箭头、字段名、类型和摘要组成完整原生按钮，最小高度为 `34px`；支持 Enter／空格，文本拖选不会触发展开切换。路径与数据复制按钮位于展开按钮外部，操作互不影响。
- 降级：不支持背景模糊时使用实色卡片；浏览器支持并启用减少透明效果偏好时关闭装饰背景，使用实色表面。原有减少动态效果、文字选择和键盘焦点提示继续保留。

本轮不增加业务功能和依赖。解析、采集、搜索与导出的实现保持原有流程。

## 操作按钮与字号规范（2026-09-28）

针对分析面板中操作看似普通文字的问题，统一调整次要操作按钮：默认即有底色、可见边框与轻微内高光；悬停增强边框和底色，按下采用强调色反馈。常规按钮最小高度为 32px，紧凑按钮为 28px，圆角为 6px；保留键盘焦点和禁用态。重建索引、分析与报告导出增加操作图标，树节点和其他工作区的次要操作沿用相同规则。

字号由统一变量管理，仅使用 12、14、16、18、20、24px。辅助文字、路径、代码、表单、按钮以及 small 标签均不低于 12px；正文为 14px，标题与关键指标按层级增大。窄屏通过页头换行、分类切换分行和工具栏整体换行适配，不再缩小字号。

页面及内部独立滚动区继续预留稳定的滚动条空间，避免内容高度改变后宽度跳动。样式静态检查、扩展类型检查和生产构建通过；本次未执行浏览器 E2E。
