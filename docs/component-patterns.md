# 组件与数据流约定

扩展由数据、SEO 和 DevTools 网络三个只读模块组成。业务模块通过 `components/ui/` 使用 Ark UI 的页签、选择框、操作菜单、折叠和提示，不在业务组件中直接定制基础交互。

业务采集由 composable 或网络会话持有，展示组件通过属性读取数据、通过事件上报读取和复制意图。主题设置使用本地存储，其余筛选、页签、选中项和展开状态留在视图实例中。

- `useInspection` 协调页面 payload 的读取、取消及文档失效；仅数据页自动采集。
- `useSnapshotSelection` 决定页面快照或独立网络响应，不修改其原始来源。
- `usePayloadViewState` 派生解码结果、分类树和关键词搜索；字段详情只访问当前解码结果。
- 数据树在对应字段行下方展开详情并共用滚动区域；行尾复制菜单通过 `UiActionMenu` 上报操作，复制值和带类型数据时才按需解析局部树。
- `useSeoInspection` 分别读取 DOM 和按需 HTML；`useSeoViewState` 持有数据来源、内容分类、分组与关键词筛选。
- `useSeoRequests` 协调手动 HEAD 和 hreflang 请求，换页、重采样、离开工作区或卸载后取消；额外请求结果独立保存，不回填原文档快照。
- `NetworkSession` 持有浏览器请求句柄、数量与缓存预算；组件只保存选中请求及正文预览上限。

异步操作必须检查当前目标与任务代次。取消、页面切换或卸载后，迟到结果不能更新界面。复制与下载共用 `useArtifactActions`，操作反馈共用 `useToast`。

SEO 资源列表只渲染当前页，CSV／TXT 导出覆盖所有筛选匹配项。原始 URL 属性和解析后的地址分别保留；页面提供的地址仅允许 HTTP(S) 打开或预览。JSON-LD 原文始终保留，Microdata 使用有界、无环的独立 JSON 表示。

字段路径是结构化段数组，区分属性、数组位置、Map 键值及 Set 位置，不执行字符串表达式。详情、搜索和视图下载必须明确展示预算；原文入口始终作为查看完整已采集内容的途径。

交互保留键盘、焦点、禁用及忙碌语义。静态背景不创建画布、观察器或持续帧循环，过渡使用简单 CSS，并尊重减少动态效果偏好。
